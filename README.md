# Squaredle Solver
CLI solver for the word game [Squaredle](https://squaredle.app/). Uses DFS to find matches for the words in the trie. Word list is taken from [norvig.com/ngrams/enable1.txt](https://norvig.com/ngrams/enable1.txt).

## Usage
To solve the daily puzzle :

`cargo run daily`

If you want to add the board manually:

`cargo run manual`
